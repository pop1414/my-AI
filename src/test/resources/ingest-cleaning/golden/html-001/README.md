# html-001

## 1. 样本定位

- 类型：原生 HTML
- 目标：验证原生 HTML 是否能保留主要语义结构，并清掉导航、页脚等噪音
- 当前状态：README 骨架已创建，待补原始文件与基线产物

## 2. 原始文件

- 文件名：待补
- 来源说明：建议构造一个含 `header/nav/main/footer`、标题、段落、列表的简短 HTML 页面

## 3. 关键失真点

- 主要正文结构被无谓降级
- 导航、页脚、边栏噪音混入正文
- 标题路径丢失或顺序混乱
- 列表、链接等语义标签被错误拍平

## 4. 覆盖目标矩阵

- `(html, 噪音混入, cleaned-md)`
- `(html, 噪音混入, chunks-preview)`
- `(html, 标题漂移, cleaned-md)`
- `(html, 结构退化, qa-ask)`
- `(html, 段落断裂, chunks-preview)`

## 5. 固定 QA 问题

1. 页面正文主要讨论了什么主题？
2. 某个小节标题下的核心观点是什么？
3. 页面中的导航或页脚噪音是否被错误带入回答上下文？

## 6. 人工审阅重点

- `cleaned.md` 是否保留主正文结构并剔除噪音
- 标题、列表、链接文本是否仍可读
- `documents/chunks/preview` 的 `sourceHint` 是否与 HTML 主标题路径一致
- 固定 QA 问题是否主要命中正文而不是导航或页脚内容
