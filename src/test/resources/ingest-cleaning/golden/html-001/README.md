# html-001

## 1. 样本定位

- 类型：原生 HTML
- 目标：验证原生 HTML 是否能保留主要语义结构，并清掉导航、页脚等噪音
- 当前状态：原始 HTML 输入已落地，可直接用于回归

## 2. 原始文件

- 文件名：`support-workflow.html`
- 来源说明：合成 HTML 页面，包含 `header/nav/main/footer`、标题、段落、列表与提示卡片，用于验证正文保留与噪音清理边界

## 3. 关键失真点

- 主要正文结构被无谓降级
- 导航、页脚、边栏噪音混入正文
- 标题路径丢失或顺序混乱
- 列表、链接等语义标签被错误拍平

## 4. 不应出现的噪音词

这些词允许存在于原始 HTML 的导航、页脚或边栏中，但不应出现在回答或 `cleaned.md` 主体正文中：

- `控制台首页`
- `队列总览`
- `运行指标`
- `相关阅读`
- `页脚热线：400-100-2000`
- `更新时间：2026-05-13`

## 5. 覆盖目标矩阵

- `(html, 噪音混入, cleaned-md)`
- `(html, 噪音混入, chunks-preview)`
- `(html, 标题漂移, cleaned-md)`
- `(html, 结构退化, qa-ask)`
- `(html, 段落断裂, chunks-preview)`

## 6. 固定 QA 问题与预期命中锚点

1. 页面正文主要讨论的主题是什么？
   - 预期命中：`分流目标`
   - 正文锚点：`区分普通文本清洗问题、结构退化问题和需要人工升级的问题`
2. “人工复核触发条件”这一节列出了哪两种需要升级处理的情况？
   - 预期命中：`人工复核触发条件`
   - 正文锚点：`同一段正文被错误切成三段以上`、`列表或表格被拍平成普通文本`
3. 如果回答里出现“控制台首页”或“页脚热线”，这说明什么问题？
   - 预期命中：`值班处理建议`
   - 正文锚点：`正文抽取和噪音清理边界出了问题`

## 7. 人工审阅重点

- `cleaned.md`：是否保留 `main` 内主正文结构并剔除导航、页脚、边栏噪音
- `documents/chunks/preview`：`sourceHint` 是否与 HTML 主标题路径一致，chunk 是否围绕 `分流目标`、`人工复核触发条件`、`值班处理建议` 切分
- `qa.ask`：固定 QA 问题是否主要命中正文，而不是导航、页脚或边栏内容
