# html-001

## 1. 样本定位

- 类型：原生 HTML
- 目标：验证原生 HTML 是否能保留主要语义结构，并清掉导航、页脚等噪音
- 当前状态：原始文件已落地，待补基线产物

## 2. 原始文件

- 文件名：`support-workflow.html`
- 来源说明：合成 HTML 页面，包含 `header/nav/main/footer`、标题、段落、列表与提示卡片，用于验证正文保留与噪音清理边界

## 3. 关键失真点

- 主要正文结构被无谓降级
- 导航、页脚、边栏噪音混入正文
- 标题路径丢失或顺序混乱
- 列表、链接等语义标签被错误拍平

## 4. 覆盖目标矩阵

- `(html, 噪音混入, cleaned-md)`
- `(html, 噪音混入, chunks-preview)`
- `(html, 标题漂移, cleaned-md)`
- `(html, 结构退化, qa-ask)`
- `(html, 段落断裂, chunks-preview)`

## 5. 固定 QA 问题

1. 页面正文主要讨论的主题是什么？
2. “人工复核触发条件”这一节列出了哪两种需要升级处理的情况？
3. 如果回答里出现“控制台首页”或“页脚热线”，这说明什么问题？

## 6. 人工审阅重点

- `cleaned.md` 是否保留主正文结构并剔除噪音
- 标题、列表、链接文本是否仍可读
- `documents/chunks/preview` 的 `sourceHint` 是否与 HTML 主标题路径一致
- 固定 QA 问题是否主要命中正文而不是导航或页脚内容
