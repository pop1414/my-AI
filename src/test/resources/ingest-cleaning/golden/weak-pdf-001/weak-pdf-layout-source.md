# 弱结构 PDF 排版草稿

> 使用说明：这份草稿不是最终 PDF，本意是给后续排版生成弱结构 PDF 时提供正文、页眉页脚和断行模式。

## 页眉与页脚建议

- 页眉：`内部评审稿`
- 页脚：`质检热线 400-900-1200`
- 页码：`第 1 页 / 第 2 页`

## 正文标题

文档清洗回归说明

### 第一节 可分块文本基底

可分块文本基底指的是在进入 chunking 之前，已经尽量消除了噪音、错误断段和标题漂移问题的正文文本。  
如果这个阶段的文本本身已经不稳定，后续不管采用普通分块还是父子分块，
都只会把错误边界继续向后传递。

为了模拟弱结构 PDF，这一节在排版时应故意把第二句话拆成多行，
让句子在视觉上出现被硬切开的效果，
但语义上仍然属于同一个自然段。

### 第二节 人工复核建议

当同一自然段被切成三段以上，或者标题和正文粘连在一起时，
不要先去调向量参数，
而应先回到 parser 和 cleaner 检查输入质量。

如果回答结果频繁引用页眉、页脚、页码或热线号码，
通常说明正文抽取边界和噪音清理边界出了问题。

### 第三节 回归观察点

1. `cleaned.md` 是否恢复了自然段连续性。
2. `documents/chunks/preview` 是否仍沿着正确标题边界切分。
3. `qa.ask` 的引用是否落在正文，而不是落在页眉页脚。

## 排版提示

- 生成 PDF 时，可将“第一节 可分块文本基底”后的两段正文手动插入额外换行
- 第二页重复页眉“内部评审稿”和页脚“质检热线 400-900-1200”
- 标题“第二节 人工复核建议”与其后第一段之间可刻意缩小段间距，增加标题粘连风险
- 不要把这份草稿直接当作 Markdown 样本使用，它的目标是后续生成弱结构 PDF
