# weak-pdf-001

## 1. 样本定位

- 类型：弱结构 PDF
- 目标：验证 parser / cleaner 对幽灵换行、标题粘连、页眉页脚噪音的修复能力
- 当前状态：README 骨架已创建，待补原始文件与基线产物

## 2. 原始文件

- 文件名：待补
- 来源说明：建议先使用人为构造的小型合成 PDF，而不是直接使用真实业务文档

## 3. 关键失真点

- 同一自然段被错误打断为多行
- 标题与正文粘连，难以稳定识别边界
- 页眉页脚、页码或重复块混入正文
- 多段落之间因为排版原因被错误拼接

## 4. 覆盖目标矩阵

- `(weak-pdf, 段落断裂, cleaned-md)`
- `(weak-pdf, 段落断裂, chunks-preview)`
- `(weak-pdf, 标题漂移, cleaned-md)`
- `(weak-pdf, 噪音混入, qa-ask)`
- `(weak-pdf, 结构退化, cleaned-md)`

## 5. 固定 QA 问题

1. 文档中对某个核心概念的定义是什么？
2. 某个章节标题下第一段正文主要讲了什么？
3. 文档是否给出了某个步骤、原则或结论？若有，请概括其内容。

## 6. 人工审阅重点

- `cleaned.md` 中标题和正文是否分离
- 幽灵换行是否得到修复，且没有错误拼接
- `documents/chunks/preview` 的边界是否比基线更合理
- `sourceHint` 是否仍能解释 chunk 来源
- 固定 QA 问题的回答与引用是否落在预期正文位置
