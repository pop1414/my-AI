# weak-pdf-001

## 1. 样本定位

- 类型：弱结构 PDF
- 目标：验证 parser / cleaner 对幽灵换行、标题粘连、页眉页脚噪音的修复能力
- 当前状态：真实 `.pdf` 输入与排版源草稿均已落地，可作为后续 parser / cleaner 回归输入

## 2. 原始文件

- 最终验收输入：`weak-pdf-regression-sample.pdf`
- 排版源草稿：`weak-pdf-layout-source.md`
- 来源说明：合成弱结构 PDF 样本，PDF 中包含正文、重复页眉页脚、页码、热线号码、故意断开的句子和标题粘连场景

## 3. 关键失真点

- 同一自然段被错误打断为多行
- 标题与正文粘连，难以稳定识别边界
- 页眉页脚、页码或重复块混入正文
- 多段落之间因为排版原因被错误拼接

## 4. 不应出现的噪音词

这些词允许存在于原始 PDF 中，但不应出现在回答或 `cleaned.md` 主体正文中：

- `内部评审稿`
- `第 1 页`
- `第 2 页`
- `质检热线 400-900-1200`

## 5. 覆盖目标矩阵

- `(weak-pdf, 段落断裂, cleaned-md)`
- `(weak-pdf, 段落断裂, chunks-preview)`
- `(weak-pdf, 标题漂移, cleaned-md)`
- `(weak-pdf, 噪音混入, qa-ask)`
- `(weak-pdf, 结构退化, cleaned-md)`

## 6. 固定 QA 问题与预期命中锚点

1. 文档中如何定义“可分块文本基底”？
   - 预期命中：`第一节 可分块文本基底`
   - 正文锚点：`在进入 chunking 之前，已经尽量消除了噪音、错误断段和标题漂移问题的正文文本`
2. “人工复核建议”这一节的第一段主要讲了什么？
   - 预期命中：`第二节 人工复核建议`
   - 正文锚点：`不要先去调向量参数，而应先回到 parser 和 cleaner 检查输入质量`
3. 如果回答里出现“第 2 页 / 内部评审稿 / 质检热线”，这通常说明什么问题？
   - 预期命中：`第二节 人工复核建议`
   - 正文锚点：`正文抽取边界和噪音清理边界出了问题`

## 7. 人工审阅重点

- `cleaned.md`：标题和正文是否分离，幽灵换行是否修复，页眉页脚与页码是否从主体中剔除
- `documents/chunks/preview`：chunk 边界是否围绕 `第一节`、`第二节`、`第三节` 切分，`sourceHint` 是否仍能解释 chunk 来源
- `qa.ask`：固定问题的回答与引用是否落在预期正文锚点，而不是落在页眉页脚、页码或热线号码
