# md-001

## 1. 样本定位

- 类型：原生 Markdown
- 目标：验证原生 Markdown 在当前链路中走最小破坏路径，不被重解析无谓降级
- 当前状态：原始 Markdown 输入已落地，可直接用于回归

## 2. 原始文件

- 文件名：`project-handoff-checklist.md`
- 来源说明：合成 Markdown 文档，包含标题、列表、表格、代码块与嵌套列表，用于验证最小破坏路径

## 3. 关键失真点

- 标题层级被改写
- 代码块围栏丢失或缩进错乱
- 表格列对齐退化
- 列表层级或空行被不必要修改

## 4. 不应出现的噪音词

原生 Markdown 样本本身没有页眉页脚噪音，以下外部样本噪音不应被引入回答或 `cleaned.md` 主体正文中：

- `内部评审稿`
- `质检热线`
- `控制台首页`
- `页脚热线`

## 5. 覆盖目标矩阵

- `(markdown, 结构退化, cleaned-md)`
- `(markdown, 结构退化, chunks-preview)`
- `(markdown, 标题漂移, cleaned-md)`
- `(markdown, 噪音混入, qa-ask)`
- `(markdown, 段落断裂, qa-ask)`

## 6. 固定 QA 问题与预期命中锚点

1. 这份文档的主要主题是什么？
   - 预期命中：`接手文档质量回归清单`、`目标`
   - 正文锚点：`判断 cleaned.md 是否足够稳定`
2. 代码块中的 `curl` 命令主要用来检查什么？
   - 预期命中：`示例命令`
   - 正文锚点：`查看当前文档在向量化前的切分预览`
3. 表格里“标题层级稳定”这一项的通过标准和常见失真分别是什么？
   - 预期命中：`指标对照`
   - 正文锚点：`h1/h2 与正文边界清晰可见`、`标题丢失、标题和正文粘连`

## 7. 人工审阅重点

- `cleaned.md`：与原始 Markdown 在语义结构上是否基本等价，代码块围栏、表格、列表层级是否仍可直接阅读
- `documents/chunks/preview`：是否沿 `目标`、`回归步骤`、`指标对照`、`示例命令` 等结构边界切分
- `qa.ask`：固定 QA 问题是否稳定引用原始 Markdown 中对应结构块，且没有引入其他样本的噪音词
