# ingest-cleaning 黄金样本与验收说明

日期：2026-05-13

状态：首批黄金样本输入与验收锚点已补齐；Markdown、HTML、Word 与弱结构 PDF 路径已完成后端验收同步

## 1. 文档目的

本文件用于定义当前 `ingest-cleaning` 轮次的固定样本、固定问题、审阅模板与验收方式，避免“优化效果”只停留在主观印象。

本轮默认围绕以下目标展开：

- 主目标：得到高质量、可分块、可回归验证的 `cleaned.md`
- 辅助验证面：`documents/chunks/preview`
- 最终回归面：固定 `qa.ask` 问题

本轮不以升级 chunk / retrieval / reference 契约为目标。

---

## 2. 验收前置条件

`src/test/resources/ingest-cleaning/golden/` 下已落地首批黄金样本、对应 README、固定问题、预期命中锚点与噪音词约束。后续 parser / cleaner 优化应以这些样本作为固定回归基线。

换句话说：

- 没有固定样本，不允许只凭印象判定优化完成
- 没有固定问题，不允许只凭单次问答偶然变好判定优化完成

## 4. 样本准备建议

本轮建议优先从**人为构造的小型合成样本**开始，而不是一上来就使用真实业务文档。

原因：

- 更容易精确制造要打击的问题
- 无需额外处理脱敏与版权问题
- 更适合反复调 parser / cleaner 规则
- 更容易在 review 时达成共同判断

## 6. 本轮硬性验收项

本轮“高质量 `cleaned.md`”只收敛到以下 5 类硬性验收项：

1. 标题层级稳定
2. 段落边界可信
3. 列表、表格、代码块结构块保真
4. 噪音可控且不误删正文
5. 对后续分块友好

以下内容**不纳入本轮硬性通过条件**：

- 页码保留
- 关键词抽取稳定
- 父子节点关系
- rich reference DTO
- 版本信息透出

---

## 7. 固定观察项

本轮不做统一质量分，只看这些具体观察项：

- 标题边界是否稳定
- 段落是否被错误断开或错误拼接
- 列表、表格、代码块是否明显退化
- 噪音是否被去除
- `sourceHint` 是否仍可解释

---

## 8. 预览验收

每个样本都应至少通过一次 `documents/chunks/preview` 回归，重点检查：

- chunk 边界是否比基线更合理
- 相邻 chunk 是否仍保留足够上下文
- `sourceHint` 是否与预期标题语义一致
- 是否出现“标题很好看，但正文仍断裂”的假改进

当前已确认：

- `md-001` 的 Markdown 标题可进入可解释 `sourceHint`，并保持表格、列表和代码块附近的结构边界。
- `html-001` 的正文标题可进入精确 JSON 形态的 `sourceHint`，普通独立短正文不会误覆盖后续 chunk 标题上下文。
- `word-001` 的标题、列表、表格和图片说明已在真实 `.docx` 解析链路中通过 `cleaned.md` 行为断言，后续 #18 可继续串联 chunk preview 与固定 QA 问题。
- `weak-pdf-001` 的中文编号标题可进入精确 JSON 形态的 `sourceHint`，并通过真实 `.pdf` 样本覆盖段落修复、标题边界、页面噪音排除和固定正文锚点。

注意：

- 本轮允许使用 preview 作为验证面
- 但不以 preview 验证之名升级 `vector metadata shape` 或 retrieval / reference 契约

## 9. QA 验收

### 9.1 固定问题策略

每个黄金样本固定 2 到 3 个问题。

问题设计要求：

- 至少 1 个问题依赖正文连续性
- 至少 1 个问题依赖标题或结构边界
- 如样本有列表、表格或代码块，可追加 1 个针对结构内容的问题

### 9.2 QA 验收目的

`qa.ask` 在本轮只作为回归验证面，不作为契约升级入口。

验收关注：

- 是否更容易召回正确 chunk
- 回答是否比基线更稳定
- 引用片段是否更接近预期正文位置

不关注：

- rich reference DTO
- 版本信息透出
- 页码、父子节点、多模态等未来字段

## 11. 审阅顺序

建议按下面顺序审阅每个样本：

1. 看原始文件和样本 README
2. 看 `cleaned.md` 是否比基线更接近人类可读正文
3. 看 chunk preview 是否切在更合理的位置
4. 再看固定 QA 问题的回答与引用

---

## 12. 一句话标准

如果某次优化不能在固定样本上让 `cleaned.md`、chunk preview 或固定 QA 问题的结果变得更稳，就不应宣称这轮 `ingest-cleaning` 已完成。
