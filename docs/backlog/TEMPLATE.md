# Backlog 条目模板

> 新增条目时复制以下格式，粘贴到 `BACKLOG.md` 对应分区。

## 模板

```markdown
### N. 标题
- **来源**: 提出者（角色）
- **问题**: 一句话描述问题
- **建议**: 具体建议方案
- **影响**: 影响范围（可选）
- **状态**: 待评估（可选，默认不写 = 已确认）
```

## 分区说明

| 分区 | 说明 |
|---|---|
| P0 | 生产事故级风险，必须尽快处理 |
| P1 | 用户可感知质量风险 |
| P2 | 开发效率与可维护性 |
| 待评估 | 需要更多信息才能决定是否实施 |

## 归档规则

- 项完成或放弃后，移动到 `archive/YYYY-QN.md`
- 每季度末整理一次
- `BACKLOG.md` 保持 ≤15 项活跃
