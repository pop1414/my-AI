# Workflows 导航

`docs/runbooks/workflows/` 用来放长期有效、跨版本复用的项目工作流文档。

这些文档不描述某一个版本“要做什么”，而描述项目长期约定的“应该怎么做”。

## 当前文件

- [my-ai-document-workflow.md](./my-ai-document-workflow.md)：文档什么时候写、写到哪一层、怎么保持和代码同步
- [my-ai-git-workflow.md](./my-ai-git-workflow.md)：分支策略、提交粒度、里程碑 tag 与日常 Git 习惯

## 使用规则

- 只有当规则在多个阶段都成立时，才放到这里
- 如果文档只是某个版本的阶段性执行方案，应该放到 `plans/`
- 如果文档是一次性的会话沉淀，应该放到 `handoffs/`
