## 1. 一句话结论

知识库列表现在已经按当前用户授权可见范围返回，不再对普通成员按工作区全量暴露知识库元数据。

## 2. 已完成规则

当前 `GET /api/v1/knowledge-bases` 规则为：

- `WORKSPACE_OWNER / WORKSPACE_ADMIN`
  - 返回当前工作区全部知识库
- `WORKSPACE_MEMBER`
  - 仅返回当前用户在 `knowledge_base_grants` 中存在 `ACTIVE` 显式授权的知识库

## 3. 本轮实际效果

### 3.1 管理员视角

管理员行为保持不变：

- 可以看到当前工作区全部知识库

### 3.2 普通成员视角

普通成员行为已收紧：

- 没有被授权的知识库不再出现在列表中
- 如果没有任何知识库授权，则知识库列表返回空数组

### 3.3 前端影响

本轮没有修改前端接口结构：

- 路径不变
- 返回字段不变
- 前端只会收到更少、更准确的条目

## 4. 实现边界

### 4.1 可见性规则落在应用层

本轮没有把过滤逻辑塞进控制器，而是放在：

- `ListKnowledgeBasesApplicationService`

这样可见性规则和业务访问规则保持在同一层治理。

### 4.2 授权真源复用

本轮直接复用现有：

- `knowledge_base_grants`

没有新增额外授权表或中间缓存模型。
