# Story 4.3: 黄金样本移除

Status: done

## Story

As a 质量维护者，
I want 从项目中移除不再需要的黄金样本测试和资源文件，
so that 消除 Tika 时代遗留的无效测试资产，保持代码库整洁，反映 Docling 迁移后的真实质量保障状态。

## Decision Record

**决策：删除黄金样本，而非重建。**

理由：
1. 黄金样本是 Tika 时代的产物 — Tika 解析质量不可控，需要回归基线捕获清洗逻辑退化
2. Docling 本身产出已足够干净，TextCleaningService 对 Docling 输出可能已是 no-op
3. 当前 `IngestCleaningGoldenSamplesTest` 仅包含 README 结构校验（无解析/分块行为断言），不构成真正的回归防线
4. `DoclingDocumentParserTest`（32 个测试）和 `DoclingDocumentChunkerTest`（13 个测试）已充分覆盖解析器和分块器的核心行为
5. Epic 1-3 已删除所有旧基线解析测试，4-3 原计划重建但不再有实际价值

## Acceptance Criteria

1. `IngestCleaningGoldenSamplesTest.java` 已删除
2. `src/test/resources/ingest-cleaning/golden/` 整个目录已删除（5 个样本目录，12 个文件）
3. 编译通过：`mvn clean compile` 零错误
4. 存量测试通过：DoclingDocumentParserTest + DoclingDocumentChunkerTest 零失败
5. 项目中不存在对已删除文件/目录的编译期引用（不会因删除导致编译失败）
