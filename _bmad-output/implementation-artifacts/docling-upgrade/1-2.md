5. Actuator health 自动暴露 Docling 连通性（`/actuator/health` 包含 docling 组件状态）。

## Dev Notes

### Arconia Docling 框架信息

- **GroupId**: `io.arconia`
- **BOM**: `arconia-bom`，使用版本 `0.20.0`（0.28.0 与 Spring Boot 3.x 存在冲突，降级后验证通过）
- **Starter**: `arconia-docling-spring-boot-starter` — 自动配置 `DoclingServeApi` Bean
- **Dev Services**: `arconia-dev-services-docling` — Testcontainers 自动启动 Docling Serve 容器
- **官方文档**: https://docs.arconia.io/arconia/latest/integrations/docling/

### 自动配置行为

`arconia-docling-spring-boot-starter` 提供以下自动配置：

1. **DoclingServeApi Bean** — 基于 Docling Java 项目，使用 Spring `RestClient` 与 Docling Serve HTTP API 通信
   - 注入方式：构造器注入 `DoclingServeApi doclingServeApi`
   - 支持文件转换（Base64 编码）和 URL 转换
   - 错误处理：`HttpClientErrorException`（4xx）、`HttpServerErrorException`（5xx）、连接超时异常
   - 程序化健康检查：`doclingClient.health()` 返回 `HealthCheckResponse`

2. **Actuator Health Indicator** — 自动配置，当 Spring Boot Actuator 在 classpath 上时生效
   - 端点：`/actuator/health` 包含 `docling` 组件
   - 禁用方式：`management.health.docling.enabled: false`
   - 检查 Docling Serve API 的 health 端点验证连通性

3. **Dev Services（Testcontainers）** — `arconia-dev-services-docling` 自动在 dev/test 模式启动 Docling Serve 容器
   - 运行方式：`./mvnw spring-boot:run` 即可，无需额外配置
   - 共享实例：`arconia.dev.services.docling.shared=true`（默认）
   - Docling UI 自动暴露：`http://localhost:<port>/ui`

### 配置属性参考

| 属性 | 默认值 | 说明 |
|------|--------|------|
| `arconia.docling.base-url` | `http://localhost:5001` | Docling Serve API 基础 URL |
| `arconia.docling.api-key` | *(空)* | API 认证密钥（可选） |
| `arconia.docling.connect-timeout` | `5s` | 连接超时 |
| `arconia.docling.read-timeout` | `30s` | 读取超时 |
