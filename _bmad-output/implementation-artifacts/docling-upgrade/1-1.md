# Story 1.1: Docker Compose 集成 Docling Serve 容器

Status: review

## Story

As a 系统运维者，
I want Docling Serve 在 docker-compose 中与现有基础设施一同编排，
So that `docker compose up -d` 一键启动全栈，无需手动管理多个服务。

## Acceptance Criteria

1. Given `infra/docker-compose.yml` 中已配置 PGVector 和 RustFS 服务，When 执行 `docker compose up -d`，Then `docling-serve` 服务正常启动，包含首次模型自动下载完成后的可用状态。
2. `docling-serve` 使用 Docker bridge 网络并暴露端口 `5001`，且服务发现名称与后续应用配置一致。
3. `docling-serve` 提供 health check，首次启动等待时间控制在 5 分钟以内，以覆盖模型下载阶段。
4. `docling-serve` 不依赖其他基础设施服务；后续 Spring Boot 应用启动时再建立对 `docling-serve` 的依赖。
