### NativeTextDecoder 当前状态

**文件：** `src/main/java/.../infrastructure/parser/NativeTextDecoder.java`（43 行）

**职责：** 按 BOM 标记（UTF-8 BOM / UTF-16LE / UTF-16BE）解码原生字节数组，无 BOM 时严格 UTF-8 解码。

**为何成为死代码：** `NativeTextDecoder` 是 `TikaDocumentTextParser` 的辅助工具——Tika 需要将原始文件字节解码为字符串后再解析。Docling 迁移后，文件内容由 Docling Serve 直接处理（Base64 编码后发送），Spring Boot 应用不再需要手动解码字节流。

**验证零引用：**
- `src/main/` 中无任何类 import 或引用 `NativeTextDecoder`
- 唯一引用：自身 + `NativeTextDecoderTest.java`
